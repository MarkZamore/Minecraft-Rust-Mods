# Приёмка обновления Rust Mods

Проверка использует настоящие `PortablePackSyncService`, `PackInstanceService` и WPF-контролы из указанного checkout LANMinecraft. Она устанавливает точную предыдущую поставку, обновляет её и повторяет обновление. Проверяются SHA-256 и размеры всех управляемых файлов, удаление прежних управляемых файлов, 12 контрольных личных файлов и оформление карточки. Мир, список вручную сохранённых серверов и резервная копия представлены синтетическими метками. Игровая механика, создание настоящей резервной копии клиентом и Steam-подключение проверяются отдельно.

Входы `old-dist` и `new-dist` содержат `pack-manifest.json` и `assets/` с точными публичными или подготовленными архивами. Рабочие файлы должны находиться внутри одного зарегистрированного стенда `LANMinecraft/artifacts/agent-runs`. Техническая установка удаляется в `finally`. В `output/report.json` сохраняются ревизии, SHA256 сборки лаунчера и результаты.

```powershell
dotnet build tools/BootstrapUpdateQa/BootstrapUpdateQa.csproj --artifacts-path $build `
    -p:LauncherRoot=$launcherSource -p:SkipPortableIdentityAdapter=true
$probe = Get-ChildItem "$build/bin/BootstrapUpdateQa" -Recurse -Filter BootstrapUpdateQa.dll |
    Select-Object -First 1
dotnet $probe.FullName $workspace $oldDist $newDist $output
```

Без дополнительных аргументов действует прежний профиль `bootstrap-only`: изменяются ровно `native/launch-rust-edition.exe` и `native/native-mods.json`, состав карточки содержит 40 модов. SHA-256 клиента, контентного пакета, пресета и остальных файлов поставки сохраняются. Проверка завершится ошибкой при другом изменении состава или управляемых файлов.

Для обновления движка с удалением Speedrun Timer, Keystrokes и Server Atlas:

```powershell
dotnet $probe.FullName $workspace $oldDist $newDist $output --engine-upgrade $packSource
```

Профиль `engine-upgrade` читает из исходников сборки `tools/mod-selection.json`, проверяет его связь по SHA-256 с `tools/mod-input-lock.json` и требует точного совпадения версий всех выбранных модов и ревизии Horizon с карточкой. Число модов берётся из этого выбора и сверяется с манифестом. Из прежнего состава допускается удалить только три запрошенных пользователем мода; остальные ID сохраняются. Число изменённых и удалённых файлов рассчитывается по точным старому и новому манифестам, затем сверяется с результатом настоящей установки. Результаты сохраняют SHA-256 обоих входных locks.

Текст `summary` и `description` профиля `engine-upgrade` должен точно совпадать с утверждённым `library/content.json` исходников сборки. Для отображаемого описания учитывается только штатное объединение строк в `CatalogPack.Description`; исходный текст метаданных сверяется без нормализации. SHA-256 утверждённого файла сохраняется в отчёте. Текущий согласованный текст состоит из пяти игровых предложений; вместо него не принимается произвольный непустой текст. Строка версии остаётся `Minecraft 26.3 (37 модов)`, ссылка на проект отсутствует, а официальные ссылки отдельных модов сохраняются. Исторический профиль `bootstrap-only` по-прежнему требует пустой `summary` и 40 модов.

Сначала обновление обязано оставить личные клавиши Orbital Laser и Waypoints, `R` Horizonmatica, настройки модов, игровые данные и прежнюю резервную копию без изменений. Затем сценарий явно применяет пресет через `ControlsPresetService`, проверяет `Insert` для Orbital Laser, `F7`/`F8` для создания и списка Waypoints, сохранение остальных настроек и повторное применение без изменений. Файл личных настроек native-модов этот шаг лаунчера не переписывает: при следующем запуске сама сборка читает соответствующие строки `options.txt`. Действие выполняется только в удаляемой технической установке.

Самостоятельная подготовка ресурсов и чтение/запись настроек точным Windows-клиентом принадлежат отдельной приёмке игры. Компиляция этого инструмента не означает PASS обновления: нужен `report.json` выполненного сценария на точных дистрибутивах.
