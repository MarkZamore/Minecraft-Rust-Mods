В каждой записи есть автор, исходный проект, лицензия, точная версия, размер, SHA256, адрес архива и подпись при наличии. Нативные порты имеют собственные ссылки проекта.

## Порты для Nightly 2ebf00a

`native_build.py` применяет проверенные по исходным SHA-256 рецепты перед официальным `horizon-mixins`:

- `physics_title_compat.py` сохраняет клики первого экрана, передаёт новый tuple/API аргумент материалу и размещает оформление воды после авторского преобразования цвета. Проверка реального WGSL для API 0.1 и 0.2 хранится в `qa/physics-shader-compat.json`.
- `spider_compat.py` квалифицирует локальные имена типов внутри отправки состояния игрока. Порядок пакетов и запись replay сохраняются; изменение позволяет штатному инструменту применить RETURN-hook Spider-Man.
- `jei_compat.py` обновляет таблицы рецептов и восстанавливает утраченную панель с сохранением поиска и истории. Проверенный порт движка добавляет отрисовку и ввод панели в творческом инвентаре; ввод творческого инвентаря вне панели сохраняется. Контроль исходного и исправленного Viewer хранится в `qa/jei-lifecycle.json`, подготовка исходников движка — в `qa/jei-creative-host.json`.
- `orbital_compat/` добавляет передачу готовых эффектов по UUID и выполняет команды через авторский тихий обработчик с действительными правами игрока. Таблица Hurricane переупаковывается по атласу получателя. Квитанция компонентных проверок — `qa/orbital-network-candidate.json`; игровая приёмка фиксируется отдельно для точного EXE.
- `server_seed_compat.py` по полным SHA-256 двух функций `add_official_server` и `add_partner_servers` отключает автоматическое добавление публичных рекомендованных серверов. Вне этих функций исходник сохраняется без изменений; общий Steam-слой отдельно проверяется по подписанной базе. Личный `servers.dat` и marker-файлы не читаются и не меняются этим рецептом. Если автор меняет функцию добавления, выпуск блокируется до переноса политики.

Клавиши Insert/R, назначения Waypoints F7/F8 по решению пользователя и резервное копирование старых миров сохраняются отдельными рецептами `orbital_controls.py` и `orbital_world_guard.py`. Конфликт точного исходника останавливает сборку для повторного переноса правки.

При следующем обновлении движка эти рецепты обязательны: их нельзя исключать из pipeline ради успешной компиляции. `build.json` и `tools/build-lock.json` закрепляют хеш всех рецептов, locks и итогового EXE. `generate_manifest.py` дополнительно отклоняет выпуск без полного игрового отчёта, сетевого отчёта без диагностических пропусков и проверки резервного копирования именно этого EXE. Актуальные файлы приёмки — `qa/orbital-startup.json`, `qa/multiplayer.json`, `qa/backup-guard.json`; они обновляются после каждого изменения клиента. Компонентные тесты и квитанция подготовки исходников не заменяют запуск Windows-клиента. Не выполненные по согласованной приёмке Steam-сценарии остаются явно отмечены `NOT RUN`.

Обязательная `qa/server-policy.json` для того же EXE подтверждает отсутствие автоматических публичных записей на новом профиле и побайтовое сохранение ручного NBT через перезапуск. Не удалять старые записи по IP, названию, marker-файлу или размеру файла: такие признаки не отличают авторскую рекомендацию от личной записи игрока.

Общий список серверов по умолчанию показывает только Steam-миры; существующие записи доступны в отдельном явно открываемом разделе, без автоматической записи favicon или переписывания неизвестных NBT-полей. Эта политика переносится вместе с общим слоем Edition и проверяется на старом и ручном списке отдельно от отсутствия нового seeding.

`qa/server-policy.json` требует шесть обычных запусков и реальные наблюдения UI по контракту `00e1c09`: девять действий в каждом запуске покрывают исходный Steam, Saved со всеми строками, обновление каждого режима, явный Steam, Back/Escape в главное меню и повторный вход со Steam. SHA файла остаётся прежним после каждого действия. Старый список в 134 байта воспроизведён из зафиксированных данных и авторского формата; он обозначается как реконструкция, а не пользовательский оригинал. Отчёт прежнего запуска без этих наблюдений выпуск не разрешает.

Шесть реальных Escape подтверждаются протоколом `edition-server-list-qa/checkpoint-v1` из закреплённого `tools/server_list_qa.py` Edition. Gate сверяет исходный SHA и согласованные ID/PID/EXE/заголовок/номер запуска и время request/ack. Native control на главном экране не заменяет desktop-ввод. Полный игровой и сетевой отчёты также должны содержать наблюдаемый числовой порт публикации в чате; отсутствие нового seeding или одно сворачивание паузы этого не подтверждают.

Общий нативный frontend уведомлений приходит из закреплённого слоя Edition и не добавляет мод. `smoke_native_notices.py` переиспользует проверяемые исходники Edition через явный `--base-repo`, адаптируя только контекст Mods и проверку неизменности его состава. Финальная `qa/native-notices.json` обязана подтвердить конечные видимые кадры, полный экран, DPI, ввод, срок жизни и свежие heartbeat для точного EXE. `launcher-notices-lock.json` и `qa/launcher-notices-support.json` отдельно закрепляют реально опубликованный поддерживающий лаунчер и его источник; эти данные не заменяют игровой прогон. Генератор требует оба доказательства и совместимость исходников общего контракта с опубликованным base-lock.

| Статус входа | Количество | Что проверяется дальше |
|---|---:|---|
| `candidate` | 32 | Пакет контента для 26.3 или нативный мод с подходящим hook API |
| `compile-probe` | 25 | Нативный мод с другим точным исходным коммитом. Проверка его планирования и компиляции на выбранном Nightly |
| `broken-upstream` | 23 | Сбой уже отмечен реестром для точного Nightly |
| `wasm-removed` | 1 | Compass Enhanced содержит `mod.wasm`, исполнение которого отключено в Horizon |
| `license-review` | 7 | Условия распространения составного клиента требуют отдельной сверки |
| `out-of-scope` | 6 | Пять шейдеров и один ресурс-пак, отдельные типы реестра |

Из версий одного проекта для пробы берётся самая свежая, которая подходит под `candidate` или `compile-probe`. Для The Basic HUD, Eating Animation и Mod Menu в lock остаются более старые кандидаты, поскольку свежие версии помечены как сломанные на этом Nightly. Все остальные версии сохраняются в `otherVersions` с причинами. Cross Version 0.7.1 отозван. Версия 0.8.0 имеет другой SHA256 и тоже не прошла локальное планирование на выбранной ревизии.

У 36 из 88 модов проверена подпись автора minisign. Остальные 52 опубликованы без авторской подписи. Для всех 88 сверены размер, SHA256, безопасные пути и метаданные фактического ZIP. Эта проверка читает архивы без выполнения их кода.

## Состав и условия поставки

- Deepbore Quarry состоит из `deepbore_quarry_native` и контентного `deepbore_quarry` версии 0.1.0. Wayfarer Stones состоит из `wayfarer_stones_native` и `wayfarer_stones` версии 0.6.0. Это пары движка и ресурсов. Оба мода контента объявляют сторону `both`. В проверенных нативных манифестах нет отдельной таблицы `dependencies`.
- Fly Speed отмечен в реестре как All Rights Reserved. Для составного клиента нужно разрешение автора. Jade отмечен CC-BY-NC-SA-4.0. KillC, RMotd и Stuck? отмечены CC-BY-SA-4.0. Classic Zoom и Serverify отмечены GPL-3.0. Условия и исходники этих компонентов проверяются отдельно перед распространением. При поставке MIT и Apache-2.0 сохраняются подтверждённые лицензии и уведомления авторов.
- `mod-license-lock.json` закрепляет уведомления всех 57 кандидатов с MIT, Apache-2.0 или CC0-1.0. Источник каждого файла указан отдельно. Это либо запись внутри проверенного архива, либо текст из официального GitHub-репозитория на точном коммите. При наличии тега версии берётся он. Иначе используется проверенный коммит источника, а лицензия версии сверяется с реестром.
- Нативная проверка совместного планирования выполняется на одной ревизии, с неизменными исходными архивами. На копиях манифестов меняется только `compatibility.horizon_revision` для пробы на выбранном Nightly, как в режиме on-base Horizon. Исходные pins остаются в lock. Совместимость, объявленная в реестре, проверяется повторно для фактического состава сборки.

## Воспроизведение

Использовать один стенд задачи из `LANMinecraft/artifacts/agent-runs/` и ту же проверенную копию исходников Horizon, что у сборки. Обычный прогон читает закреплённый lock. Режим `lock --write` применяется при намеренном обновлении реестра.

```powershell
python -B tools/inspect_mods.py lock --registry-file "$run/registry.json"
python -B tools/inspect_mods.py inspect --work $run --openssl $openssl --include-broken
python -B tools/mod_licenses.py --archives "$run/archives" --destination "$run/license-cache"
python -B tools/inspect_mods.py plan --work $run --workspace $horizonSource --mixins $mixins `
  --candidate-singles --jobs 2 --result "$run/singles-plan.json"
python -B tools/inspect_mods.py plan --work $run --workspace $horizonSource --mixins $mixins `
  --case horizon_physics --case smoothie_capes --case horizon_physics,smoothie_capes `
  --result "$run/cape-plan.json"
```

Для проверки использован `horizon-mixins-cli 0.6.0` на закреплённом Horizon коммите инструмента `e8cd0aa38cffef49cb2e088ef716baa107148c02`. Планировщик принимает источник с `.horizon-revision` или реальным Git HEAD. Для распакованной подписанной копии без маркера допустимо передать `--revision-git-dir` с bare Git-метаданными ровно проверенного коммита. Источник остаётся доступен только для чтения.

В [снимке проверки](qa/registry-plan-evidence.json) 49 из 55 индивидуальных нативных планов прошли. Шесть планов отклонены из-за отсутствующих функций исходной ревизии. Это Cross Version, Eating Animation, Freecam, Mod Menu, Visuality и Waymap. Gyro также отклоняется отдельно из-за коллизии с модулем игры. Промежуточный совместный план 46 модов прошёл с 381 внедрением, а его компиляция выявила удалённые типы и методы у The Basic HUD. [Диагностика компиляции](qa/combined-compile-probe.json).

В первом выпуске для выбранных 41 нативного мода применены 335 внедрений и 76 модулей. В составе также два контентных компонента. Выбор пользователя для семи прежних конфликтов и сочетания клавиш Orbital Laser хранится в одном журнале решений. [Закреплённые решения](conflict-decisions.json).

Политика окружения принадлежит сборке: `launcher/environment-defaults.json` содержит только `DISABLE_VULKAN_OW_OVERLAY_LAYER=1`; `stage_mod_pack.py` проверяет точную карту и создаёт `presentation.json:environmentDefaults`. Generic-ограничения: не более 16 ASCII-имён длиной 1–64 по `[A-Za-z_][A-Za-z0-9_]*`, строковые значения до 1024 байт UTF-8 без управляющих символов, общий бюджет имён и значений до 8192 байт, без повторов имён без учёта регистра. Bootstrap применяет defaults только к команде клиента, сохраняя наследуемое значение даже если оно пустое, и явные значения/удаления Command. Новая политика не меняет хеш игрового ядра или рецепт Steam-слоя, но требует актуального bootstrap и повторной приёмки по SHA presentation; прежние отчёты того же EXE не подходят. Механизм адресного отключения неявного слоя описан в [Khronos LoaderLayerInterface](https://github.com/KhronosGroup/Vulkan-Loader/blob/main/docs/LoaderLayerInterface.md).
