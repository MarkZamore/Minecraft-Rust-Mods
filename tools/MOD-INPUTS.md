# Входы Minecraft Rust Mods

Игра закреплена на Horizon Nightly `66f3981f522b24c250b21523a70080965b940424`, Minecraft 26.3, hook API 411. `mod-input-lock.json` хранит каждый проект из [официального реестра Horizon](https://horizon-rust.github.io/horizon-mods/index.json) от 6 ноября 2026 года, 00:21 UTC. В каждой записи есть автор, исходный проект, лицензия, точная версия, размер, SHA256, адрес архива и подпись при наличии. Нативные порты имеют собственные ссылки проекта.

Orbital Laser 0.5.9 добавлен из отдельного официального релиза автора. Снимок реестра и его строки сохранены. `official-mod-sources.json` закрепляет SHA256 архива и опубликованного `SHA256SUMS`, коммит автора, оригинальный манифест и производный `orbital.hmod`. Пакет ресурсов состоит из 241 исходной записи. Лицензия MIT берётся с точного коммита. [Релиз Orbital Laser](https://github.com/Stink-O/orbital-laser/releases/tag/v0.5.9).

| Статус входа | Количество | Что проверяется дальше |
|---|---:|---|
| `candidate` | 32 | Пакет контента для 26.3 или нативный мод с подходящим hook API |
| `compile-probe` | 25 | Нативный мод с другим точным исходным коммитом. Проверка его планирования и компиляции на выбранном Nightly |
| `broken-upstream` | 23 | Сбой уже отмечен реестром для точного Nightly |
| `wasm-removed` | 1 | Compass Enhanced содержит `mod.wasm`, исполнение которого отключено в Horizon |
| `license-review` | 7 | Условия распространения составного клиента требуют отдельной сверки |
| `out-of-scope` | 6 | Пять шейдеров и один ресурс-пак, отдельные типы реестра |

Из версий одного проекта для пробы берётся самая свежая, которая подходит под `candidate` или `compile-probe`. Для The Basic HUD, Eating Animation и Mod Menu в lock остаются более старые кандидаты, поскольку свежие версии помечены как сломанные на этом Nightly. Все остальные версии сохраняются в `otherVersions` с причинами. Cross Version 0.7.1 отозван. Версия 0.8.0 имеет другой SHA256 и тоже не прошла локальное планирование на выбранной ревизии.

У 36 из 88 модов проверена подпись автора minisign. Остальные 52 опубликованы без авторской подписи. Для всех 88 сверены размер, SHA256, безопасные пути и метаданные фактического ZIP. Эта проверка читает архивы без выполнения их кода.

## Состав и условия поставки

- Deepbore Quarry состоит из `deepbore_quarry_native` и контентного `deepbore_quarry` версии 0.1.0. Wayfarer Stones состоит из `wayfarer_stones_native` и `wayfarer_stones` версии 0.6.0. Это пары движка и ресурсов. Оба мода контента объявляют сторону `both`. В проверенных нативных манифестах нет отдельной таблицы `dependencies`.
- Fly Speed отмечен в реестре как All Rights Reserved. Для составного клиента нужно разрешение автора. Jade отмечен CC-BY-NC-SA-4.0. KillC, RMotd и Stuck? отмечены CC-BY-SA-4.0. Classic Zoom и Serverify отмечены GPL-3.0. Условия и исходники этих компонентов проверяются отдельно перед распространением. При поставке MIT и Apache-2.0 сохраняются подтверждённые лицензии и уведомления авторов.
- `mod-license-lock.json` закрепляет уведомления всех 57 кандидатов с MIT, Apache-2.0 или CC0-1.0. Источник каждого файла указан отдельно. Это либо запись внутри проверенного архива, либо текст из официального GitHub-репозитория на точном коммите. При наличии тега версии берётся он. Иначе используется проверенный коммит источника, а лицензия версии сверяется с реестром.
- Нативная проверка совместного планирования выполняется на одной ревизии, с неизменными исходными архивами. На копиях манифестов меняется только `compatibility.horizon_revision` для пробы на выбранном Nightly, как в режиме on-base Horizon. Исходные pins остаются в lock. Совместимость, объявленная в реестре, проверяется повторно для фактического состава сборки.

## Воспроизведение

Использовать один стенд задачи из `LANMinecraft/artifacts/agent-runs/` и ту же проверенную копию исходников Horizon, что у сборки. Обычный прогон читает закреплённый lock. Режим `lock --write` применяется при намеренном обновлении реестра.

```powershell
python -B tools/inspect_mods.py lock --registry-file "$run/registry.json"
python -B tools/inspect_mods.py inspect --work $run --openssl $openssl --include-broken
python -B tools/mod_licenses.py --archives "$run/archives" --destination "$run/license-cache"
python -B tools/inspect_mods.py plan --work $run --workspace $horizonSource --mixins $mixins `
  --candidate-singles --jobs 2 --result "$run/singles-plan.json"
python -B tools/inspect_mods.py plan --work $run --workspace $horizonSource --mixins $mixins `
  --case horizon_physics --case smoothie_capes --case horizon_physics,smoothie_capes `
  --result "$run/cape-plan.json"
```

Для проверки использован `horizon-mixins-cli 0.6.0` на закреплённом Horizon коммите инструмента `e8cd0aa38cffef49cb2e088ef716baa107148c02`. Планировщик принимает источник с `.horizon-revision` или реальным Git HEAD. Для распакованной подписанной копии без маркера допустимо передать `--revision-git-dir` с bare Git-метаданными ровно проверенного коммита. Источник остаётся доступен только для чтения.

В [снимке проверки](qa/registry-plan-evidence.json) 49 из 55 индивидуальных нативных планов прошли. Шесть планов отклонены из-за отсутствующих функций исходной ревизии. Это Cross Version, Eating Animation, Freecam, Mod Menu, Visuality и Waymap. Gyro также отклоняется отдельно из-за коллизии с модулем игры. Промежуточный совместный план 46 модов прошёл с 381 внедрением, а его компиляция выявила удалённые типы и методы у The Basic HUD. [Диагностика компиляции](qa/combined-compile-probe.json).

В первом выпуске для выбранных 41 нативного мода применены 335 внедрений и 76 модулей. В составе также два контентных компонента. Выбор пользователя для семи прежних конфликтов и сочетания клавиш Orbital Laser хранится в одном журнале решений. [Закреплённые решения](conflict-decisions.json).
