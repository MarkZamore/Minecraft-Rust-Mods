# Управление Minecraft Rust Mods

Пресет сборки содержит 62 базовых назначения Horizon 26.3 и три назначения модов: колесо Orbital Laser и два действия Waypoints. Всего 65 назначений. Базовые значения сверены с `horizon-client-input/src/keybinds.rs` на закреплённой ревизии и с опубликованным пресетом Minecraft Java Edition. Сочетания F3 и клавиши режима наблюдателя сохраняют исходные контексты. Шаблон `configureddefaults/options.txt` задаёт версию формата 5023 для первого применения до запуска игры.

Лаунчер загружает `launcher/controls-preset.txt` отдельным небольшим архивом и применяет его после подтверждения игрока. В точном клиенте проверяется чтение и повторная запись этих назначений вместе с отдельной личной настройкой.

Дополнительные сочетания Rust-модов настраиваются в **Options → Mods**. Horizon хранит их в `horizon-mods.txt` с ключами `key.<id мода>.<действие>`. Колесо Orbital Laser по умолчанию открывается клавишей `Insert` с целеуказателем в руке. Для него сборка читает и сохраняет `key_orbital.wheel` в `options.txt`, чтобы применение пресета и смена клавиши в игре использовали одно назначение. При первом запуске старый файл без этой строки сохраняет прежнее личное назначение, если оно было. Horizonmatica сохраняет поворот схемы клавишей `R` в режиме перемещения. Пресет назначает создание точки Waypoints на `F7`, список точек на `F8`. После применения пресета `N` и `M` остаются для перемещения схемы и меню Horizonmatica. Без применения нового пресета клиент сохраняет прежние личные назначения.

В таблице ниже приведены авторские значения; пресет разводит действия Waypoints, как описано выше.

| Клавиша | Действия с совпадающими авторскими значениями |
|---|---|
| `G` | Fullbright & NoFog переключает яркость в мире, где также доступны быстрые действия Horizon. Inventory Profiles использует эту клавишу для быстрой перекладки в контейнере. |
| `N` | Fullbright & NoFog переключает туман, Waypoints открывает создание точки, Horizonmatica переключает перемещение схемы. |
| `M` | Waypoints открывает список точек, Horizonmatica открывает главное меню. |
| `K` | Armor HUD переключает числа, Horizonmatica переключает принтер. |
| `V` | Toggle Sprint переключает режим бега, Horizonmatica переключает показ схемы. |
| `Z` | Zoom приближает камеру, Spider-Man выполняет рывок при подходящем снаряжении. |
| `R` | Mouse Tricks сортирует инвентарь, Inventory Profiles сортирует при выключенных кнопках сортировки, JEI открывает рецепт предмета на своей панели. |

Совпадения найдены в исходниках закреплённых архивов. Срабатывание зависит от экрана, состояния и настроек мода. См. [точные входы сборки](mod-input-lock.json) и [общие правила пресетов LANMinecraft](https://github.com/MarkZamore/LANMinecraft/blob/main/tools/CONTROLS-PRESETS.md).
